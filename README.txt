IN MY WORLD — PEST CONTROL NIGHTMARE v0.2

Visual upgrade to the original v0.1 prototype.
Preserves original logo, mission, movement, spraying, inspection, camera and mobile controls.
Adds roof geometry, detailed exteriors, landscaping, neighborhood detail, van detailing, character detailing and indoor props.

To deploy on GitHub Pages: upload index.html and assets/logo.png to the repository root (not inside MyWorld_Game_Prototype). The Three.js library is loaded from a CDN, so internet access is required.

For testing locally, open index.html in a browser.
