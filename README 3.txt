IN MY WORLD — PEST CONTROL NIGHTMARE v0.4 (MODEL-READY BUILD)

IMPORTANT: This ZIP DOES NOT contain realistic human 3D models yet. The supplied character illustrations are 2D and cannot be converted automatically into accurate rigged 3D assets. The previous geometric technician remains a FALLBACK.

NEW: Shawn, Latasha, and Irvon character selector; separate speed settings; a GLB/GLTF loading pipeline for real textured 3D characters, animation support, original mission and controls retained.

TO ADD ACTUAL 3D CHARACTERS LATER:
Upload properly licensed, rigged and textured GLB files at:
 assets/characters/shawn.glb
 assets/characters/latasha.glb
 assets/characters/irvon.glb
They must be genuine 3D models. Character switching automatically loads them. This ZIP includes an empty assets/characters folder as a placeholder.

TO DEPLOY ON GITHUB PAGES FROM IPHONE:
1. In Files, unzip this ZIP.
2. In your GitHub repository, replace the existing ROOT index.html with this ZIP's index.html. Be careful: iOS may rename duplicates index 2.html; GitHub Pages won't use that by default.
3. Keep assets/logo.png in the existing assets folder.
4. Open https://dailent13.github.io/In-my-world-game/ after the deployment completes.

Three.js loads from CDN, so an internet connection is needed.
